# 🎓 Student Management System

A simple Student Management System built in Python using Object-Oriented Programming (OOP).

## ✨ Features

- ➕ Add Student
- 📋 Display All Students
- 🔍 Search Student by Roll Number
- ❌ Remove Student
- ✏️ Update Student Marks
- ✅ Pass/Fail Status
- 🖥️ Menu-driven interface

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Git
- GitHub

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/codewithaayush-lang/Student-Management-System.git
```

2. Open the project folder

```bash
cd Student-Management-System
```

3. Run the program

```bash
python main.py
```
